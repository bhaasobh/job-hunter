# 🎯 AI Job Hunter

Automatically finds job matches from your CV using Claude AI + web search, and sends results to your Telegram.

---

## ⚡ Quick Setup (5 minutes)

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Configure local environment values

Copy the safe template and fill in your private values:
```bash
cp .env.example .env
```

Never commit `.env`. The application loads it automatically with `python-dotenv`.

### 3. Get your Telegram credentials

**Bot Token:**
1. Open Telegram → search `@BotFather`
2. Send `/newbot` and follow the steps
3. Copy the token it gives you

**Chat ID:**
1. Start a chat with your new bot (send any message)
2. Open this URL in your browser (replace TOKEN):
   `https://api.telegram.org/botTOKEN/getUpdates`
3. Find `"chat":{"id": 123456789}` — that number is your Chat ID

### 4. Add your CV
Edit `cv.txt` and replace the sample content with your actual CV.

### 5. Customize job preferences
Open **Advanced job search** in the website and edit locations, job types, and
excluded keywords. These preferences are saved in your browser and applied to
future searches.

---

## 🚀 Running

**Run once manually:**
```bash
python job_hunter.py
```

**Run on schedule (4x per day):**
```bash
python scheduled_ai_hunt.py
```

The scheduler runs every four hours, scores only new/untested jobs with Ollama,
and sends up to 10 matches scoring at least 75/100 to Telegram. Configure it
with `SCHEDULE_INTERVAL_HOURS`, `SCHEDULE_MIN_AI_SCORE`, and
`SCHEDULE_MAX_TELEGRAM_JOBS`. On an empty database, the first run creates a
silent baseline so old listings are not all sent as new. Set
`SCHEDULE_BOOTSTRAP_SILENT=false` to disable that behavior.

## Web interface

Create and activate a virtual environment, install the dependencies, and start the local website:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python web_app.py
```

Open http://127.0.0.1:5050 and click **Search jobs**. The website fetches jobs without sending Telegram notifications or writing them to MongoDB. Results can be filtered by keyword, company, location, and remote status.

You can also upload a PDF, DOCX, or TXT CV. The website extracts its text
locally, recommends search preferences, and ranks results with a 0-100 CV match
score generated by the local Ollama model. The original uploaded file is kept
in memory only and is not sent to an external AI service.
Published requirements and responsibilities are extracted from each job when
available. Ollama compares required and preferred skills, experience, education,
programming languages, tools, and relevant previous experience. Open a job's
**Details** view to see strong, partial, missing, and critical matches.

Install and start Ollama before starting the website, and make sure the configured
model is available:

```bash
ollama pull qwen3.8
ollama serve
```

The defaults use `http://127.0.0.1:11434/api/generate` and model
`qwen3.8:latest`. Override these in `.env` with `OLLAMA_URL`, `OLLAMA_MODEL`,
or `OLLAMA_TIMEOUT_SECONDS` (600 seconds by default for large local models).
When a CV is active, searching automatically runs the model only for jobs with
local status `new` that have not already been AI-tested; older, saved, applied,
and previously tested jobs are skipped. You can also choose **Analyze with AI**
on any untested individual job. The persistent `ai_analyzed` flag and AI result
are stored in `jobs.db`, so a tested job is not analyzed again. The first
analysis can take longer while Ollama loads the model. The **Use AI analysis**
checkbox beside **Search jobs** is enabled by default; clear it to search without
automatically scoring new jobs.

Website results are saved locally in `jobs.db` (SQLite). Each job starts as `new`, becomes `old` when it appears in more than three searches, and can be marked `saved` or `applied` from the table. Saved and applied statuses are preserved by future searches.

The search currently supports Greenhouse, Workday, Comeet, SmartRecruiters, Qualcomm, NVIDIA, Ashby, Elbit Systems, ISCAR, Israeli banks, Israel Civil Service, Amazon, Apple, Google, and Microsoft job feeds.
